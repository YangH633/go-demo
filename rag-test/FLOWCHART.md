## 详细数据流图

### 文档处理数据流

```
原始文档 (PDF/文本)
    │
    ▼
[PDF Parser] → 纯文本
    │
    ▼
[Text Chunker] → [块1, 块2, 块3, ...]
    │
    ▼
[BGE-M3 Embedding] → [向量1, 向量2, 向量3, ...]
    │
    ▼
[Qdrant Storage] → 持久化存储
```

### 查询处理数据流

```
用户问题
    │
    ▼
[BGE-M3 Embedding] → 问题向量
    │
    ▼
[Qdrant Search] → 相关文档块 (Top-K)
    │
    ▼
[Context Builder] → 上下文文本
    │
    ▼
[Qwen2.5 7B] → 最终答案
    │
    ▼
返回: {答案, 来源文档}
```

## 关键技术点

1. **文档解析**: 使用 pdftotext 工具提取 PDF 文本
2. **文本分块**: 按字符数分块，保留重叠以维持上下文
3. **向量化**: BGE-M3 模型生成 1024 维向量
4. **相似度搜索**: Qdrant 使用余弦相似度进行向量检索
5. **上下文增强**: 将检索到的文档块作为上下文输入 LLM
6. **生成答案**: Qwen2.5 7B 基于上下文和问题生成答案

## 性能优化建议

1. **批量处理**: 文档分块后批量生成嵌入向量
2. **缓存机制**: 缓存常见问题的嵌入向量
3. **异步处理**: 文档上传可异步处理，立即返回
4. **索引优化**: Qdrant 集合使用合适的索引参数
